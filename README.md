# 桌宠（Windows 桌宠小游戏）

一个跑在 Windows 系统托盘上的桌面宠物：养一张透明 PNG 小人，摸头、喂食、扔出去在屏幕上弹跳、
还能吸附到其它窗口顶沿挂着；累了点右键菜单「休息」——透明度在 25%↔75% 间缓缓正弦渐变 30 秒后
体力回满；背景图贴地铺在人物后面、随人物走动居中；本地音乐加入播放列表循环播放。
还有**启动问候、眨眼动画（支持多帧序列 + 触发概率）、一键切换状态图、待办清单（到期提醒 + ♥ 待办随机催促）、
自定义关键词聊天**。
**像素级点击穿透**——宠物是透明像素的地方，鼠标能直接点到桌面/其它程序，只有实心像素可以交互。
纯 Electron，无第三方运行库、无原生 Node 模块（窗口枚举用编译好的 C# 小程序）。

> 功能现状速查：**正在运行的功能说明.md**（逐行对源码整理，2026-09-08 版）。
> 用户视角使用说明：**USAGE_GUIDE.md**。调参：**TUNING.md**。

## 运行

前置：Node ≥ 18、npm（Electron 已作为 devDependency 锁定）。

```bash
npm install        # 首次安装 Electron
npm start          # 启动桌宠
```

> 安装依赖很慢？设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 走国内镜像。

### 换图即定制（素材根目录）

**设计初衷已从"多宠物切换"改为"换图即定制"**：应用内不再提供更换宠物的交互，
个性化 = 直接替换素材文件（重启生效）：

| 素材 | 位置 | 说明 |
| --- | --- | --- |
| 宠物主图 | `项目文件夹\data\assets\pet\pet.png` | 手动替换这个文件即完成换宠；推荐透明背景 PNG |
| 眨眼动画帧 | 同目录 `blink-*.png`（需在 `config.js` 的 `blinkAnim.frames` 配置路径才会启用） | 多帧序列 + 每帧时长 + 触发概率 |
| 状态切换图 | 同目录 `state-*.png`（或内置 `src/assets/state.png`） | 「切换状态 ▸ 状态图」显示的形象（尺寸可与主图不同，独立等比缩放） |

应用内**不提供**浏览/修改素材根目录的入口（防误改）；背景图与 BGM 的上传功能不受影响

## 便携化（整个文件夹拷走即用）

所有数据（设置 `settings.json`、素材 `assets/`、缓存）都存在应用文件夹内的 `data\` 里，
**不写 `%APPDATA%`、不写注册表**。把整个文件夹（含 `node_modules`）拷到别的 Windows 电脑，
**双击 `启动桌宠.bat` 即可直接用**（不需要装 Node.js）；素材、待办、聊天规则、背景、音乐全部跟着走。
settings 里的文件路径都是相对 `data\` 的，改文件夹名字、换盘符也不会失效。
（见下）。想改菜单文本/各处文案/眨眼动画：编辑 `src/shared/config.js`（或可选的
`src/shared/baked-defaults.json` 固化层）。

### 交互一览

| 操作 | 效果 |
| --- | --- |
| 左键单击宠物 | 摸头（Q 弹 + 情绪互动） |
| 按住宠物拖动 | 1:1 直接跟手（**无惯性/缓动/重力**） |
| 快速甩动后松开 | 抛掷 → 重力/惯性/边界反弹/落地压扁（**托盘可关物理**） |
| 低速在靠近窗口顶沿处松开 | 宠物**吸附**到那个窗口顶沿（挂在上沿） |
| 左键按住 ≥ 3s | 锁定（最高置顶级 `'screen-saver'` + 整窗彻底点击穿透；呼吸动画照常）→ 再长按一次或托盘解锁 |
| 右键按住 ≥ 1.5s | 弹出 Windows 风格主菜单（休息/喂食/**待办**/**聊天**/音乐/背景/**切换状态**/重置状态/退出） |
| 右键菜单「休息」 | 透明度在 25%↔75% 间**缓慢正弦渐变**闪烁，30s 后停止、体力回满 |
| 托盘图标 | 隐藏/显示、**锁定并保持始终置于顶层**/解锁（**解锁保底入口**）、吸附开关、**物理模拟开关**、主菜单、区域设置、退出 |
| 启动 | 宠物就位 0.5s 后头顶弹一句随机问候（8 条，可定制），5s 消失、点击提前关 |
| 眨眼 | 配了多帧动画 → 按触发概率播放帧序列；未配置 → 每 2.8~6.2s 用 `src/assets/blink.png` 闭眼 90~210ms |

任何"状态归零"（情绪/体力/饱食任一 ≤0）时，宠物会变成半透明；任一恢复到 >0 立即复原。
启动时会按离线时长一次性结算；隐藏窗口期间也暂停计时并在恢复显示时结算。
「休息」的闪烁与"归零半透明"相互独立：休息用正弦覆盖，结束时按状态恢复正常（无归零即 100%）。
托盘「物理模拟」关掉后：人物甩出不抛、悬空松开不下坠，**拖到哪就停在哪**；但"贴近窗口顶沿低速松开"仍能**吸附**（吸附功能独立于物理开关）。

### 背景图（用户上传，始终可用）

- 通过右键菜单「背景 → 选择背景图片…」（应用内选择器，仅 PNG）设置；图**底边永远贴在桌面（活动区域地面）**，
  高度自动缩放为人物高度的 4/3，宽度按原图比例。
- 人物站在地面上走动时，背景**水平居中跟随人物脚底**；把人物抛到空中/拎起时背景原地不动，落地后重新对齐。
- 右键菜单「清除背景」可随时复原（画面立刻清空，再次选择又能显示）。不透明度 25/50/75/100% 可调。

### 音乐（用户上传，始终可用）

- 右键菜单「音乐 → 添加音乐…」打开应用内选曲（MP3 / WAV / OGG / FLAC / M4A / AAC），
  选中一首点「把这首加入播放列表」即拷贝进 assets 并开始播放，可连续加多首（Esc 结束）。
- 「播放/暂停」「下一首」「上一首」「停止播放」管理列表。当前无音量调节 UI，默认音量在
  `src/shared/config.js` 的 `audio.volumeDefault`（0.6）里改。
  > 注：自动化测试只能验证"加入列表 + 进入播放态"，**真实出声请人工确认**（见 MANUAL_CHECKLIST）。

> 背景/音乐都走**应用内选择器**（不弹系统对话框）——本机"透明+置顶+全屏"宠物窗在场时系统对话框
> 确认后拿不到所选路径，这是实测踩坑后的取舍。上传的文件会复制进用户数据目录持久化，原图删除不影响。

### 待办清单 / 随机催促 / 聊天

- **待办**：右键菜单「待办…」→ 独立窗口。添加（截止时间精确到分钟 + ♥ 重要）、完成划线、删除；
  数据持久化。后台每 30s 检查，到期未完成 → 桌宠气泡"主人，该做'xxx'了！"（5s，点击关闭）。
- **随机催促**：平均 25~30 分钟随机一次，从 ♥ 待办里按紧迫度加权挑一条（越临近概率越高），
  气泡"主人，'xxx' 做完了吗？"（8s）。锁定/隐藏时不催。
- **聊天**：右键菜单「聊天 ▸ 聊天」开聊天窗、「聊天设置」配规则（关键词 → 回复，忽略大小写、
  多命中取最长关键词）；没匹配上 → 桌宠被"点一下"（Q 弹 + 情绪变化）。规则持久化。

### 眨眼动画 / 切换状态

- 眨眼：**支持多帧动画**——在 `config.js` 的 `blinkAnim.frames` 里配置帧序列（每帧单独时长）与整体触发概率（0~100%），
  每次眨眼机会按概率依次播放帧序列后恢复常态；**未配置任何帧时降级**为原有单图眨眼
  （`src/assets/blink.png`，替换同名文件即可，需与主图同尺寸，每 2.8~6.2s 闭眼 90~210ms）。
- 切换状态：右键菜单「切换状态」子菜单有**「主宠物图」「状态图」两个单选项**——**切换 = 换一具身体**：
  状态图自己走完整解码管线（等比缩放/像素分析/锚点），切换后像素级判定、拖动、抛掷、吸附、呼吸 Q 弹、
  背景跟随等**全部功能照常作用于新身体**；切换保持"底边中点"位置连续（原地换装）；
  状态数值不受影响；眨眼只属于主宠物形象。状态图可替换（`config.js` 的 `stateImage.path` / 素材根目录同名文件）。

## 玩法参数都收在哪

全部可调参数集中在一个模块：`src/shared/config.js`（不可变对象），并在 **TUNING.md** 逐条说明。
想改手感/速度/衰减速率，只改这一个文件即可。

## 像素级点击穿透是怎么做的

- 整个"活动区域"是**一个**无边框、透明、置顶、不进任务栏的窗口。
- 主进程每 ~16ms 推送真实光标屏幕坐标到渲染层。
- 渲染层每帧用 `pet.bitmap` 的**原始像素**做命中测试（`pixel.js`），并读取已打开的 UI 矩形。
- 命中 → `win.setIgnoreMouseEvents(false)`（接收鼠标）；未命中 → `setIgnoreMouseEvents(true, {forward:true})`（点击穿透）。
- **锁定态永远整窗穿透**，动画照常；托盘是解锁保底入口。
- 判定与表现完全解耦：动画变形（呼吸/Q 弹/眨眼动画）只发生在 CSS transform 或叠加图层上，不改动任何像素判定区域。
